# Output Recommendation

Source basis: tools PDF pages 16-17, Causal Layered Analysis.

Recommended default output: `text`.

Causal Layered Analysis moves from surface events to systems, worldviews, and deep metaphors. Text is recommended because the four layers must be explicit and inspectable before any visual synthesis.

Best output data:
- Litany or surface event
- System causes
- Worldview
- Myth or metaphor
- Reframed question
- Narrative rewrite direction

Use image or multimodal only for a labelled layer diagram or metaphor visualization after the analysis is complete.
