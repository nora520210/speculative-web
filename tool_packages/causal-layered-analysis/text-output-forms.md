# Text Output Forms

Source basis: `思辨设计tools-3.pdf`, Causal Layered Analysis / 因果分层分析, pages 16-17.

## Default Form

Use a four-layer excavation table, a reframed question, a metaphor-swap table, and interpretive questions.

1. **Layered excavation.** Use rows for Litany, System, Worldview, and Myth/Metaphor. Use columns for `What is visible or said`, `Underlying assumption`, and `Evidence or interpretation`.
2. **Reframed question.** State one concise question that is changed by the deeper analysis.
3. **Metaphor swap.** Use a table with `Dominant metaphor`, `Alternative metaphor`, and `What the alternative makes discussable`.
4. **Questions for the deeper layer.** Ask at least three questions that retain ambiguity and distinguish evidence from interpretation.

## Selection Rule

Prefer this form when an apparently operational problem may conceal a worldview, a value hierarchy, or a governing narrative.

## Rendering Contract

Emit `table`, `callout`, `table`, and `questions` blocks. Do not turn CLA into a technical-fix checklist.
