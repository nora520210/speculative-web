# Causal Layered Analysis

## Source Logic

Causal Layered Analysis moves from surface events to system causes, worldview assumptions, and deep myths or metaphors.

In this project it helps turn a scientific or social issue into a more critical design question by exposing the values and narratives beneath the surface.

## When To Use

- A problem looks technical but contains hidden values or narratives.
- A scenario feels shallow because it only reacts to visible symptoms.
- The user needs a reframed question before generating futures or artifacts.

## Recommended Inputs

Use a problem statement, research note, headline, policy issue, public controversy, or generated scenario.

## Recommended Outputs

The first output should be a four-layer text map. Later outputs can produce a layer diagram, reframed artifact brief, or visual prompt.

## Misuse Risks

- Treating the method as a root-cause analysis only.
- Skipping worldview and metaphor layers.
- Producing a moral claim without source traceability.
