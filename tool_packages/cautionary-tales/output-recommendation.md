# Output Recommendation

Source basis: tools PDF page 11, Cautionary Tales.

Recommended default output: `multimodal`.

Cautionary Tales extend a current trend toward an unwanted everyday consequence. Multimodal output is useful because the warning becomes stronger when the written consequence is paired with a concrete public-facing artifact, satirical object, or everyday scene.

Best output data:
- Current trend
- Negative extension
- Daily consequence
- Who pays the cost
- Hidden values
- Public discussion questions
- Warning artifact or negative scene prompt

Avoid disaster imagery. The output should stay close to ordinary life so people can discuss the trend's hidden costs.
