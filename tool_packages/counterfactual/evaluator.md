# Evaluation Checks

An output passes this tool if:

- It clearly names the original condition.
- It clearly names the altered fact.
- The alternate world follows from the altered fact.
- At least two products, institutions, behaviors, or value judgments differ from the present.
- Speculative artifacts or institutions make the alternate reality inspectable.

Reject or revise if:

- No branch point is specified.
- More than one core fact changes without explanation.
- The causal chain is vague.
- The output does not help question the present.
