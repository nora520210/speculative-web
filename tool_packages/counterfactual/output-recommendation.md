# Output Recommendation

Source basis: tools PDF pages 7-8, Counterfactuals.

Recommended default output: `text`.

Counterfactuals need a named altered fact and a traceable causal branch. Text should come first because the user must be able to see what changed, why the parallel reality follows, and how products, institutions, behavior, or values differ.

Best output data:
- Original condition
- Altered fact
- Counterfactual world state
- Causal changes
- Speculative artifacts or institutions

Use image or multimodal after the alternate world has produced a clear artifact, institution, brand, document, or visual anomaly.
