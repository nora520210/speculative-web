# Text Output Forms

Source basis: `思辨设计tools-3.pdf`, Counterfactuals / 反事实推演, pages 7-8.

## Default Form

Use a before/after divergence table, a causal ledger, a short fragment from the parallel present, and inevitability questions.

1. **Point of divergence.** Compare `Present condition`, `Altered fact`, and `Immediate divergence`. There must be one identifiable altered fact.
2. **Causal ledger.** Use a table with `Because`, `Institution or practice changed`, and `Everyday consequence`. Each row must trace back to the altered fact.
3. **Fragment from the parallel present.** Write a brief notice, diary entry, institutional excerpt, or routine scene that lets the alternate world be inferred rather than merely explained.
4. **What does the present call inevitable?** Ask at least three questions that put the real present back under examination.

## Selection Rule

Prefer this form when a historical, institutional, ownership, or technical path is being treated as unavoidable.

## Rendering Contract

Emit two `table` blocks, then a `paragraph` and a `questions` block. Never use an alternate-world summary without a visible causal branch.
