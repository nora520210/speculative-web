# Counterfactuals

## Source Logic

This tool changes an already existing historical fact or current condition and builds a parallel reality that could have been otherwise. It helps users escape the assumption that the present was inevitable.

The tool should make a clear branch point, then trace how products, behaviors, institutions, organizations, and values would differ today.

## When To Use

- The team is trapped in linear future thinking.
- The project needs another technological, institutional, industrial, or social history.
- The goal is to question why the current reality feels natural.

## Key Question

If one key fact were replaced, how would today's products, behaviors, organizations, and value judgments differ?

## Misuse Risks

- Producing an arbitrary alternate world with no causal relation to the changed fact.
- Changing too many facts at once.
- Treating the output as fantasy rather than a structured thought experiment.
