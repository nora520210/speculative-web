# Output Recommendation

Source basis: tools PDF page 16, Dator's Four Futures.

Recommended default output: `text`.

Dator's Four Futures generates structurally different scenario drafts: growth, collapse, discipline, and transformation. Text is recommended because the four futures need to stay comparable across shared dimensions before any one is visualized.

Best output data:
- Growth scenario
- Collapse scenario
- Discipline scenario
- Transformation scenario
- Comparison dimensions
- Narrative branch points

Use image or multimodal only after the four scenarios are clear enough to create distinct visual prompts.
