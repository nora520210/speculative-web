# Text Output Forms

Source basis: `思辨设计tools-3.pdf`, Dator's Four Futures / 四种未来, page 16.

## Default Form

Use a four-futures comparison matrix, a branch-point ledger, and pre-selection questions.

1. **Four structurally different futures.** Compare Growth, Collapse, Discipline, and Transformation in one table. Use columns for `Dominant rule`, `Everyday scene`, `Who benefits or bears cost`, and `Material signal`.
2. **Branch points.** Use a table with `Decision or disruption`, `Paths it opens`, and `Assumption it challenges`.
3. **Questions before choosing a future.** Ask at least three questions that stop the group from prematurely selecting an attractive branch.

## Selection Rule

Prefer this form when a team is trapped in an implicit growth narrative or needs comparable scenario alternatives.

## Rendering Contract

Emit two `table` blocks and one `questions` block. The four futures must not be four moods of the same future.
