# Dator's Four Futures

## Source Logic

Dator's Four Futures uses four archetypes to break single-path thinking: continued growth, collapse, discipline or constraint, and transformation.

In this system it is useful when a research topic is being imagined only as "more of the same" or only as a positive technology story.

## When To Use

- The team is overcommitted to a growth narrative.
- A topic needs structurally different scenarios before artifact generation.
- The user wants comparison across multiple future logics.

## Recommended Inputs

Use a domain or research topic plus the dominant assumption currently guiding discussion. Stakeholders and constraints improve the scenarios.

## Recommended Outputs

The first output should usually be structured text or a four-quadrant comparison table. Later multimodal outputs can turn one branch into an image prompt or artifact brief.

## Misuse Risks

- Producing four moods instead of four logics.
- Treating collapse as spectacle rather than a systemic failure mode.
- Treating transformation as magical escape from constraints.
