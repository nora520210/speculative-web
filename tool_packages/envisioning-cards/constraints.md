# Model Constraints

- Produce card-like prompts with short labels and concrete questions.
- Include stakeholder, time, value, and pervasiveness or diffusion categories.
- Make each card actionable for critique or revision.
- Do not answer all questions for the user; preserve reflective openness.
- For image output, represent cards or a workshop review scene in black-and-white or document-like visual language unless the user asks otherwise.
