# Output Recommendation

Source basis: tools PDF pages 18-19, Envisioning Cards.

Recommended default output: `text`.

Envisioning Cards are an ethics and reflection layer. Text is recommended because the useful data is a set of prompts, question cards, and review checklists that force attention to stakeholders, time scales, values, and diffusion.

Best output data:
- Question cards
- Stakeholder prompts
- Long-term impact prompts
- Value conflict prompts
- Diffusion consequences
- Review checklist

Use image or multimodal only when the card text is already written and needs a printable or visual card layout.
