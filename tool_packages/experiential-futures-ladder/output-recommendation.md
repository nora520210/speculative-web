# Output Recommendation

Source basis: tools PDF pages 17-18, Experiential Futures Ladder.

Recommended default output: `multimodal`.

Experiential Futures Ladder moves from abstract future context to scenario, situation, and tangible stuff. Multimodal output is recommended because the method is designed to turn foresight into embodied artifacts, service moments, scenes, or props.

Best output data:
- Future context
- Scenario
- Situation
- Stuff
- Experience script
- Artifact or scene prompt

Do not skip the ladder. The tangible output must remain grounded in the context, scenario, and situation.
