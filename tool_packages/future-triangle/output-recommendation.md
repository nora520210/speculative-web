# Output Recommendation

Source basis: tools PDF pages 14-15, Futures Triangle.

Recommended default output: `text`.

Futures Triangle is an analytic mapping tool. Structured text should first separate pulls of the future, pushes of the present, and weights of the past. A diagram can follow, but only after the forces are named.

Best output data:
- Pulls of the future
- Pushes of the present
- Weights of the past
- Key tensions
- Intervention opportunities

Use image or multimodal only for a labelled force-map or triangle diagram specification.
