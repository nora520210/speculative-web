# Text Output Forms

Source basis: `思辨设计tools-3.pdf`, Futures Triangle / 未来三角, pages 14-15.

## Default Form

Use a force inventory table, a non-predictive discussion-weight chart, a tension table, and intervention questions.

1. **Forces shaping the issue.** Identify Pulls of the Future, Pushes of the Present, and Weights of the Past. Use columns for `Force`, `Signal or evidence`, and `How it changes the system`.
2. **Discussion weight of forces.** Use 1-5 bars only to show which forces deserve collective attention. Values are not forecasts or evidence scores.
3. **Tension pairs and intervention wagers.** Use a table with `Tension`, `What becomes difficult`, and `Small intervention to test`.
4. **Questions that alter the triangle.** Ask at least three questions about which force could be strengthened, weakened, or reinterpreted.

## Selection Rule

Prefer this form before artifact generation when a system is simultaneously pushed, pulled, and constrained.

## Rendering Contract

Emit `table`, `bar_chart`, `table`, and `questions` blocks. Name forces before proposing interventions.
