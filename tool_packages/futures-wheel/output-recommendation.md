# Output Recommendation

Source basis: tools PDF pages 15-16, Futures Wheel.

Recommended default output: `text`.

Futures Wheel is about consequence chains. Text should come first because the key distinction is between first-, second-, and third-order effects. This structure can later become a diagram, but the readable chain is the core output.

Best output data:
- Seed change
- First-order effects
- Second-order effects
- Third-order effects
- Risk and opportunity priorities

Use image or multimodal when a labelled wheel diagram is needed as a secondary visualization.
