# Futures Wheel

## Source Logic

Futures Wheel starts with one change, event, policy, or technology and expands outward into first-, second-, and third-order consequences.

For this project, the tool helps a scientific input become a chain of social, institutional, material, and visual implications.

## When To Use

- The user has a seed event but not a full scenario.
- The project needs to find indirect consequences.
- A later artifact or image should be based on a specific implication chain.

## Recommended Inputs

Use one seed change. Add stakeholders, system boundaries, and time horizon when available.

## Recommended Outputs

Structured text is the safest first output. A visual wheel or graph can be generated later as a diagram brief or image prompt.

## Misuse Risks

- Creating a flat brainstorm list.
- Treating consequences as certain.
- Skipping affected groups and institutional side effects.
