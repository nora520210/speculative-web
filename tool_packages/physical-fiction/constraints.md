# Model Constraints

- Produce a concrete artifact, prototype, prop, document, label, exhibit, or object scene.
- Make material details visible: form, surface, labels, wear, scale, packaging, interface, or placement.
- Explain the implied users, rules, institutions, and tensions without turning the output into a sales pitch.
- Preserve fictionality: the artifact should facilitate imagining, not pretend to be a deployable product.
- For image output, avoid abstract illustration and generate an inspectable artifact or documentary scene.
