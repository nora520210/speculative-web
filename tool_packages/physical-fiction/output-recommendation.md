# Output Recommendation

Source basis: tools PDF page 3, Physical Fictions.

Recommended default output: `multimodal`.

Physical Fiction materializes a fictional world as an inspectable object, prop, prototype, label, or exhibit. It should normally produce an artifact brief plus an object or scene prompt, because the tool's value comes from letting viewers infer the wider world through material detail.

Best output data:
- Artifact description
- Use scene
- Implied world rules
- Viewer inference questions
- Object visual prompt

Avoid product-pitch language. The artifact should remain visibly speculative rather than pretending to be a market-ready product.
