# Output Recommendation

Source basis: tools PDF pages 8-11, Reductio ad Absurdum.

Recommended default output: `multimodal`.

Reductio ad Absurdum pushes an accepted claim to an extreme until its logic becomes absurd. The recommendation is multimodal because the critique usually needs both a written escalation and a concrete absurd artifact, process record, task, or system visual that makes the contradiction inspectable.

Best output data:
- Accepted claim
- Extreme extension
- Absurd outcome
- Revealed problem
- Critical discussion
- Absurd artifact or process prompt

Keep the absurdity tied to the original claim. Random comedy is not a valid output for this tool.
