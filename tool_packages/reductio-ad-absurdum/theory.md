# Reductio ad Absurdum

## Source Logic

This tool temporarily accepts a common claim, assumption, or logic and pushes it to an extreme until it produces an absurd result. The absurdity is not random comedy; it is a way to reveal a hidden problem in the original logic.

It is especially useful for critiquing technological rationality, efficiency worship, over-quantification, and invisible system dependencies.

## When To Use

- A daily system or belief is treated as obvious.
- The project needs to expose complexity, dependency, absurd cost, or unsustainability.
- A critique should be shown through an extreme task, prototype, record, or process.

## Key Question

If we really followed this logic to the end, what ridiculous, unsustainable, or unbearable result would appear?

## Misuse Risks

- Producing absurdity that is funny but not critical.
- Losing the original claim being tested.
- Making the output too random to function as an argument.
