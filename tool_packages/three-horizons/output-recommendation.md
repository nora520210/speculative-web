# Output Recommendation

Source basis: tools PDF pages 19-20, Three Horizons.

Recommended default output: `text`.

Three Horizons maps transition from the current system to emerging alternatives through present practices. Text is recommended because the core data is a transition structure: H1, H2, H3, tensions, and action priorities.

Best output data:
- H1 current system
- H2 transition practices
- H3 emerging future
- Tensions
- Action priorities
- Stop/protect/try recommendations

Use image or multimodal for a diagram or roadmap only after the transition logic is explicit.
