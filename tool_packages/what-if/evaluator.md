# Evaluation Checks

An output passes this tool if:

- It contains a clear what-if question.
- The changed condition is specific.
- Consequences are grounded in everyday life.
- Stakeholder impacts are visible.
- It produces material for debate, such as risks, key objects, or discussion questions.

Reject or revise if:

- The output only summarizes the source topic.
- It is a generic future vision.
- It lacks a concrete changed condition.
- It treats the scenario as a forecast.
