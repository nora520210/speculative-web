# Output Recommendation

Source basis: tools PDF pages 6-7, What-Ifs.

Recommended default output: `text`.

What-Ifs are strongest as written scenario seeds. The tool turns a broad issue into a sharp "What if..." condition, then names everyday consequences, affected groups, risks, and value questions. Text should come first because the premise must be clear before image or artifact generation.

Best output data:
- What-if question
- Changed condition
- Short scenario
- Affected stakeholders
- Risks and value questions

Use image or multimodal only after the premise points to a concrete scene, object, service, rule, or social consequence.
