# Text Output Forms

Source basis: `思辨设计tools-3.pdf`, What-Ifs / 假设情境, pages 7-8.

## Default Form

Use a condition card, an ordinary-day vignette, a stakeholder impact table, and open questions.

1. **What changes?** State one sharp, contestable condition in a callout. Do not change several premises at once.
2. **An ordinary day under this rule.** Write a short situated vignette. Show a bodily, social, labour, consumption, or governance consequence.
3. **Who is reorganized?** Use a table with `Actor`, `Gain or burden`, and `New everyday behaviour`.
4. **Questions that resist closure.** Ask at least three questions that expose trade-offs, rights, or unequal effects. Do not solve them.

## Selection Rule

Prefer this form whenever the input is broad or abstract. Use a plain paragraph only when the user explicitly asks for a compact premise.

## Rendering Contract

Emit `callout`, `paragraph`, `table`, and `questions` blocks. Localize all labels to the requested response language. Never express the table as Markdown pipe syntax.
